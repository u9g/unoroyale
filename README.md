# Card Royale

Public home of the [Card Royale!](https://apps.apple.com/us/app/card-royale/id6761205942) card game.

- [Privacy policy](PRIVACY.md)
- [Support](SUPPORT.md)

The releases here are the game bundles the app downloads over the air, and the `gh-pages` branch is the web build. Both are published by CI from the source repo.
